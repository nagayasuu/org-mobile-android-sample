# org-mobile-android-sample

Android アプリ開発のためのサンプルプロジェクトです。現在は開発手順と Git 運用規約を整備しています。アプリ本体、Gradle Wrapper、CI ワークフローは今後追加します。

## 開発ドキュメント

- [開発手順](docs/development-workflow.md)：最小の機能を実装し、ビルド、テスト、CI、端末での動作確認につなげる手順。
- [Git 運用規約](docs/git-workflow.md)：ブランチ、コミットメッセージ、PR、レビュー、統合のルール。
- [AGENTS.md](AGENTS.md)：agent が作業開始時に読む指示。

## 現在の状態

実行できるアプリやビルド・テストコマンドはまだありません。開発環境と実行手順は、実装と動作確認に合わせて [開発手順](docs/development-workflow.md) を更新します。
