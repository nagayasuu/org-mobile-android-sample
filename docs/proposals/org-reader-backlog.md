# Org Reader のメモ機能バックログ

Android で思いついたことを短く残し、必要に応じてメモを整理し、関連するメモをたどれるようにする。`.org` 文書を読んでいる途中にもメモを残せるようにする。現在の閲覧機能と制約は [アプリ仕様](../project/app-spec.md)を参照する。

## 機能候補

上から仮の着手順。次に取り組む1件の受け入れ条件を具体化し、その機能を試した結果から残りの順番を見直す。基本機能がそろった時点で、引き続き取り組む項目を GitHub Issues に移す。

- [ ] **1行メモを残して読み返す。** 本文だけで保存し、あとで一覧から開く。
- [ ] **残したメモを整理する。** 元のメモを見ながら、あとで意味が通じるタイトルと本文に整える。
- [ ] **メモ同士をつないでたどる。** 関連するメモを選んでリンクを付け、リンク先からも参照元を開く。
- [ ] **読書中にメモを残す。** 文書を読みながら出典付きのメモを書き、保存後に同じ箇所へ戻る。
- [ ] **メモから出典を開く。** メモから元の文書の該当箇所へ戻る。

Emacs 向けの `.org` 書き出しは、Android で書いたメモを PC でどう使うかが具体化した時点で検討する。

## 次に検討する機能

**1行メモを残して読み返す。** 思いついた一文を端末に残し、あとで読み返せるようにする。

### 受け入れ条件案

- 「新規メモ」から本文を1行入力して保存すると、一覧から開いて読み返せる。アプリを再起動しても本文が残る。
- 本文が空白だけの場合は保存できない。保存に失敗した場合は、入力を保ったまま再試行できる。
- メモ一覧から文書に戻ると、開いていた `.org` を同じ位置から読める。

「書く」と「読む」を行き来する操作を試してから、タブ構成を決める。
