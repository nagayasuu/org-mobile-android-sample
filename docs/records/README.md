# 記録

現在の手順や仕様の正本は [開発文書の案内](../README.md)から参照する。ここには過去の対象版・環境・根拠・判断を残す。

- `decisions/NNNN-short-title.md`：影響が広い設計判断。作成条件と記載項目は [ADR の手順](../workflow/design.md#設計判断を-adr-に記録する)に従う。現在、個別の ADR は未作成。
- `verification/YYYY-MM-DD-short-description.md`：ビルド・テスト・文書・Git 設定などの検証記録。
- `evaluations/YYYY-MM-DD-short-description.md`：開発フロー・agent 運用の比較結果と採否。

過去の成功を現在の変更の成功とみなさない。文書再構成に伴い、本文のローカル参照や再実行用の文書パスは現在の配置へ更新している。過去の実行対象は記録にあるコミット・差分・環境で識別し、その版の原文を履歴で確認する。ローカル専用資料・設定・生ログは公開記録へ含めない。

固定済みの評価プロトコル・集約値の JSON は `evaluations/` に置き、内容と SHA-256 を保持して移動した。JSON 内のプロンプトや入力パスは過去の隔離環境を表す固定データであり、現在の作業指示や現在のパス一覧には読み替えない。
