## 対象と受け入れ条件

利用者の依頼に従い、今回再構成した全公開ファイルを [保守チェックリスト](../../maintenance/agent-instructions.md)の19項目と照合し、不足を修正する。対象は `docs/reorganize-agent-guidance` の未コミット差分と非除外の新規公開ファイル。再構成自体の対象と根拠は [前回の作成者記録](2026-11-14-agent-guidance-reorganization.md)と[独立レビュー](2026-11-14-agent-guidance-review.md)を参照する。空だった旧 notes・verification ディレクトリは利用者の追加依頼で削除済み。

前回の差分を維持し、合否基準の値・R01〜R30・許可範囲・アプリの動作は変更しない。確認結果と根拠を残し、修正した文書の例と参照経路が動作することを確認する。コミット・push・外部投稿は行わない。

## 検証と再利用の判断

実行者は作成 agent。環境は同じ作業環境の Python 3・Git、対象は本記録を含む現在の公開作業ツリー。

| ID | 実行・照合 | 結果 |
| --- | --- | --- |
| V1 | agent-tools の `PY_CHECK` 付きコードブロックをそのまま実行し、現存公開 Markdown を検査。`git diff --check` | 本記録追加前は62文書387ローカルリンク成功。記録追加後も検査し、最終結果を独立レビューに残す |
| V2 | `context change --max-chars 32000 --include docs/guides/agent-tools.md document-tools check-output`、`context review`、`read docs/workflow/verification.md 共通の検証` | 終了0。新しい再利用条件を共通検証に含め、追加節を含む実例も取得可能。絶対URLの照合は独立レビューに記録 |
| V3 | 前回レビューの対象一覧と現在の document_tools.py・check_commit_message.py・test_agent_tools.py の SHA-256 を比較 | 3件すべて一致。今回の変更は文書のみで、Python の入力形式・依存・実装・テスト・環境は不変のため、前回の98件失敗なし・6 skipをその対象範囲で参照。文書本文と実例は前回結果を流用せずV1・V2で再検査 |

Android の本体・テスト・設定・利用経路の変更がないため APK 再生成・Android E2E は対象外。CI は push・PR を行わず未実行。任意 Kotlin 構文木環境を要する6件は前回同様未実行で、今回成功したとは扱わない。

今回も既存環境の公開文書・必要差分のみを扱い、AI利用条件は [前回レビューのE9](2026-11-14-agent-guidance-review.md)が参照する利用者確認の範囲で継承する。利用先や共有対象の拡大、外部サービス契約の独立監査は行っていない。
