## 目的・受け入れ条件

文書の全文再読、不要な中間出力、検証根拠の転記を減らす手順を、既存の公開手順と skill に反映する。

- 全作業の共通事項と作業別の参照先を示し、関係する要件や依存先は読み足す。
- 検証結果を対象版・実行者・環境・終了コードとともに一度記録し、参照できるようにする。出力を短くしても失敗・警告・未確認事項は残す。

- 公開ファイルだけで手順を理解できるようにし、アプリ・ビルド・CI の変更や、新しい検証スクリプトの導入は含めない。

- 文書差分の判定：採用可。統合判断は対象コミットの必須 CI を確認するまで保留する。
