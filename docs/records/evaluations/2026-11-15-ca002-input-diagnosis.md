# CA-002：読取入力増加と指示重複の切り分け

作成者：主担当 Codex agent。基準 HEAD：`9647051`。対象は公開済みの集約記録・固定プロンプト・指示書だけ。過去の生ログ・私的資料・認証情報は読み込まず、新規の比較用モデル実行も行っていない。数値と候補全文・SHA-256 は[診断集約](2026-11-15-ca002-input-diagnosis.json)に保存した。既存の試行値は当時の環境での観測であり、現在の指示書の効果ではない。

## 目的・比較条件と受け入れ条件

[CA-002](../../proposals/codex-adoption-remaining-tasks.md)の「新規実行前に既存記録を調べる」に従い、次の順で診断した。

1. 11月13日と14日の比較群を分け、役割別に取得可能な値と欠測を列挙する。再開・失敗を除外せず、作者の再利用分を二重計上しない。
2. 総入力、コマンド数、返却文字数、返却記録、メタデータ、通常読取との併用を切り分ける。文字数をトークンに換算せず、コマンド数を読取回数とみなさない。
3. 常時指示・条件付き資料・引き継ぎの重複を調べ、引き継ぎだけから重複説明を除く候補を一要因で静的比較する。CA-009の英語化、モデル設定、ツール設定、確認者の構成は変更しない。
4. 全担当の入力・時間・条件欠落・再調査を比較できなければ運用への採用は見送る。必須指示、原文確認、独立レビュー、R01〜R30を削らない。

今回の予算は新規比較モデル0回、追加課題0件。静的比較の成功条件は指定文字列以外の不変と、削除対象の規則が入口・正本に残ること。これを実作業の品質や入力削減の証明にしない。運用への採用条件は従来同様、品質低下なし、全担当・失敗込みの入力/成功10%以上減、完了時間中央値の悪化20%以内、全担当usage取得とする。静的比較では後者を判定できない。
