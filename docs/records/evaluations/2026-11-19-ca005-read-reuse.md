# CA-005 節取得・既読範囲再利用の評価と採否

## 比較条件

基準版は `cc2b1413ee60244f1f4389e9e446505adcf5b359`。Linux x86_64、Python 3.13.16 で、同じ担当が共通手順と評価手順を取得した後、文書取得の手引きを追加で求める作業を模擬した。切り替える要因は返却記録の利用だけ。両条件とも `python3 scripts/document_tools.py context change --max-chars 32000` に、初回は `--include docs/maintenance/evaluation.md codex-adoption-evaluation`、追加時はさらに `--include docs/guides/agent-tools.md document-tools` を指定した。候補だけに同じ新規の `--state` と `--reader` を指定した。記録は Git 除外先に一時作成し、終了時に削除した。 [文書取得ツールの手引き](../../guides/agent-tools.md#document-tools)

実行前に対照→候補の順で各1巡、その後に候補の追加要求へ `--refresh` を付けた回復確認1回を固定した。比較用モデルは0回、取得コマンド最大5回、各3秒・全体20秒、各返却32,000文字（末尾改行を除く）が上限。非ゼロ終了・上限超過・原文不一致で停止する。機械的な成功条件は、初回・追加で得られる原文が対照と候補で一致し、2回合計の stdout が候補で減ること。モデルを含む運用の採否には、既存比較の品質維持・全担当 usage 取得・成功あたり総入力10%以上減・完了時間中央値の悪化20%以内を用いる。 [既存比較の固定条件](2026-11-14-context-token-evaluation.md#実行前の計画)

## ローカル比較

基準版のファイルと SHA-256 を照合し、返却された各行のパス・行番号・本文を原文と比較した。文字数は Unicode 文字で数え、原文は行本文、残りはパス・行番号・メタデータ・区切り・改行。時間は取得プロセスの起動から stdout 捕捉までの単発値。準備・原文照合・レビューは含めない。

| 条件と段階 | 要求／返却原文行 | 原文文字 | その他の文字 | stdout の文字数 | 時間（ミリ秒） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 記録なし・初回 | 293／293 | 17,741 | 3,392 | 21,133 | 57.3 |
| 記録なし・追加 | 370／370 | 21,877 | 3,870 | 25,747 | 50.8 |
| 記録あり・初回 | 293／293 | 17,741 | 3,900 | 21,641 | 54.2 |
| 記録あり・追加 | 370／77 | 4,136 | 2,610 | 6,746 | 60.4 |
| 記録あり・回復確認（追加要求に `--refresh`） | 370／370 | 21,877 | 4,379 | 26,256 | 76.0 |

両条件とも同じ370行を取得した。記録ありでは追加に必要な77行がすべて返り、初回の293行は省略された。2回合計の stdout は46,880→28,387文字（39.45%減）。初回だけでは記録ありのメタデータが508文字多い。回復確認では370行すべてが再出力された。追加の後でこの回復が1回必要なら、記録ありの累計は54,643文字になる。回復確認の理由は、初回に返った本文を保持できなかった場合の全範囲復元を試すため。通常作業の発生率、時間改善、トークンへの換算は未判定。

## 判定

主担当 Codex の判断は **任意利用の試行継続、既定化と追加のモデル比較は見送り**。ローカル比較では必要な原文を保って返却量を減らせた。既存の実作業比較では、文書と画面層テストの成功あたり入力がそれぞれ5.02%・17.22%増えた。解析は失敗したレビュー担当の usage と再開レビューの完了時間が欠測し、全体の時間基準と総入力10%以上削減は未判定。今回の返却量や単発のプロセス時間は、その欠測を補う根拠に使わない。 [既存比較の結果](2026-11-14-context-token-evaluation.md#実行結果)

保守担当は、今後の同種作業で同一担当・同一版・同一範囲の再読が再取得の主因として繰り返し観測され、全担当の使用量と独立した品質判定を取得できる見込みが立った時点で再比較を検討する。その場合、返却記録の有無だけを変え、refresh の理由・追加取得・手戻り・完了時間を同じ区間で記録する。切り詰めに対する初回範囲の比較は CA-002 で追跡する。 [評価手順](../../maintenance/evaluation.md#codex-adoption-evaluation)
