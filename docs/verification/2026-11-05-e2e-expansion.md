## 対象と受け入れ条件

作成者は Codex。比較元は CI 修正を統合した `9f6cf9ba717dbaeedd0950116105c3f93e01f0e9`。
利用者の指示に従い、CI 修正の成果物照合・別 agent のレビュー・PR #24 の統合を終え、次に本変更へ進んだ。
既存の3件を保ったまま、標準ファイル選択を通す次の5件を追加する。

| 条件 | 合格条件 |
| --- | --- |
| 空文書 | 前の内容を消し、空文書の案内を表示し、再選択で復帰 |
| 同一ファイルの更新 | 同じ URI を更新し、再選択後に新しい162ブロックと先頭位置を検査 |
| 1万項目 | 10,003ブロックを保持し最後の項目・見出し・本文を表示 |
| 表示設定 | 文字200%・密度4/3倍、端末の夜間設定オン／オフと横向きで操作・本文へ到達。設定を復元 |
| アクセシビリティ | ATF による可視画面の検査、見出しと本文のノード属性を検査 |

対象は選択可能な行の最小高さ、E2E テスト、テスト依存、CI のステップ名、README と手引き、本記録。
実行は JDK 17 / API 37 Google APIs x86_64 / Pixel 2 / swangle の専用エミュレーター。
コマンドは `check assembleDebug :app:assembleDebugAndroidTest :app:pixel2Api37DebugAndroidTest` に
`-Pandroid.testoptions.manageddevices.emulator.gpu=swangle` を付ける。
ローカルの環境固有パス・認証情報・生成物は公開対象に含めない。

## 計画と検証経過

1. 既存動作に対して5件を追加し、共通検証と E2E を実行する。
2. 検証が示した実際の問題だけを修正し、必要な検証を実行する。既に満たしている仕様を Red にするために壊さない。
3. 別 agent が R01〜R30を確認し、PR の必須 CI・手動 E2E・成果物照合後に統合する。

初回は8件中7件成功・1件失敗（終了1、全体2分34秒）。ATF の TouchTargetSizeCheck が、
選択可能な行の高さ33dp（6件）・38dp（1件）を検出した（Red）。
文字と表示サイズ・夜間設定・回転後の設定復元、1万項目を含む他7シナリオは成功した。
これはコンパイルや環境の不備ではなく、実際のタッチ対象が小さい問題である。
OrgAdapter の選択可能な行に最小高さ48dpを設定する。ATF のエラー抑制や合否条件の緩和は行わない。

別 agent のレビューで、更新後の文書が短いと先頭へ戻る条件を自然な位置の補正だけで満たす恐れが指摘された。
更新前に160項目の途中へ移動し first>0 を確認、更新後も160項目を維持して first=0 を検査するよう変更した。
更新後の全162ブロックと末尾の更新項目も照合する。

修正後は上記コマンドが終了0、全体2分44秒（Green）。Debug / Release の JVM テストは各40件成功、
Lint・APK生成も成功。E2E は8件すべて成功し、失敗・error・skipは0、XMLの時間は109.169秒だった。
本体 APK SHA-256 は `8a965fc9430fc8197438e35a229afb41b8c2e5fd5240bf922f89926f198d16ab`。
PNG8件・UI階層XML8件と参考値JSONを出力した。JSONは入力138,968bytes・10,000項目、
クリックから最初の内容検査まで1,020ms、PSS101,110KB、Java heap10,164,672bytes。
これは今回のローカル環境の単発参考値で、CI や性能基準の結果と混同しない。
actionlint、ローカル文書参照先、差分の空白も検査して成功した。

## 保証の範囲と残る課題

1万項目の時間は選択クリックから最初の内容検査完了まで、メモリは末尾表示後の
アプリ＋instrumentation の PSS・Java heap。単発 Debug 観測であり、性能の閾値・ピーク値・Release ベースの反復計測は未対応。
アプリは明るいテーマを維持する。端末の夜間設定での表示検査を、暗色テーマ対応とは扱わない。
TalkBack の音声・読み順、主観的な使いやすさ、実機固有の挙動は未確認。
Dropbox は専用環境未準備という利用者の回答に従い、[準備方法](../android-build.md#dropbox-経路の準備未実装)を残し、接続テストは未実装とする。
保守担当者が、専用環境の準備時・表示や読み込み条件の変更時に一覧を再検討する。
