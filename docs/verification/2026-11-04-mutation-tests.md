## 閾値と意図的な誤実装（V3）

31件すべてが意味のある mutation で、改善後は全件を検出できたため最低スコア100%を採用。
低下を許す余裕は設けない。PIT の検出扱いには `TIMED_OUT` なども含み得るため、
XML の全件が `KILLED` であることと両対象クラスの mutation の存在も検査する。
対象や演算子・版を変更した場合は新たな生き残りをレビューして閾値の根拠を再確認する。

次の一時的な誤実装では対象の具体例・プロパティテストを seed 42 で実行し、
コンパイル・環境エラーではなくアサーション失敗で検出した（各終了1）。

| 一時的な誤り | 失敗した代表テスト |
| --- | --- |
| 見出しレベルを常に1に固定 | 日本語の見出し・リストの具体例、見出しの深さを検証する性質 |
| parse 終了時の段落 flush を削除 | 対応外構文の保持、未終了リテラル、解析の独立性 |
| 不正 UTF-8 の REPORT を REPLACE に変更 | 不正 UTF-8 の拒否を検証する具体例と性質 |

追加した3つの具体例を一時的に外すと、PIT の84%を100%の閾値が拒否した（終了1）。
一時変更はすべて撤去し、正しい実装・追加済みテストで専用タスクが成功した（終了0）。
正規表現内の構文変更・fluent API の引数変更は既定演算子で網羅できない。
特に decoder の自動 mutation は1件に限られ、高スコアだけで UTF-8 の十分性は保証しない。

まだ評価できず、AGP と自作の接続部分の継続互換性も未確認なので CI への追加は保留する。
保守担当者が解析・デコードの次の変更時に再実行し、実行時間・ノイズ・追加不足・
調査負担を記録する。複数回の安定した結果が得られた段階で対象変更時の CI を再判断する。
通常のプロパティテストは引き続き既存の必須 CI に含める。

CI は未実行：コミット・push・PR 作成は今回の依頼に含めていない。
統合前に対象コミットの既存 `verify` の結果を確認する。
端末・利用者評価は対象外：本番コード・UI・実行時依存の変更がないため。
共有範囲は公開コード・合成入力のみで、私的な文書・URI・認証情報は使用していない。
