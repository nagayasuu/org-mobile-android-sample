# AGENTS.md を改善するためのチェックリスト

このチェックリストは、情報漏洩、データ消失、依頼の範囲を超える操作、不具合の見落としを防ぐために、このリポジトリ固有の要件を確認するものである。
既存の設定や指示では対応できていない要件と、繰り返し発生する誤りへの対策に絞り、必要な手順を具体的に示すために使う。
各項目は、AGENTS.md 本文と、読むよう指定した参照先を合わせて確認する。

- [ ] 規則や手順の説明をそれぞれ一か所で管理し、必要なときに参照できるようにしているか。
- [ ] 各指示の実行条件と行動が明確で、解釈が分かれる曖昧な表現を避けているか。
- [ ] 変更の範囲と期待する結果を、作業ごとに定める手順と記録先を示しているか。
- [ ] 作業ごとに読むべき文書や節と、それらを読む条件を明記しているか。
- [ ] 参照先が存在し、共有されている文書・コード・設定から必要な手順を確認できるか。
- [ ] 記載したコマンドが実在し、現在の設定や他の指示と矛盾していないか。
- [ ] 変更を禁止するデータと、維持する必要がある互換性を具体的に示しているか。
- [ ] このプロジェクトで許可されている操作と、追加の承認が必要になる条件を明記しているか。
- [ ] 公開や外部への送信を禁止する情報と、その保存場所を具体的に示しているか。
- [ ] 変更の種類ごとに、必要な検証コマンド、実行条件、合否基準、検証の対象外とする条件を示しているか。
- [ ] レビューが必要かどうかと、必要な場合の確認者および確認範囲を示しているか。
- [ ] 変更の種類に応じて、検証とレビューの結果・根拠を、どこにどのように記録するかを示しているか。
- [ ] 内容が変わっていない既読資料を再利用する条件を示しているか。
- [ ] 過去の検証結果を再利用する場合、今回の変更と実行環境にも有効か確認するよう定めているか。
- [ ] ログや根拠の重複掲載を減らし、必要な内容を参照できるようにしているか。
